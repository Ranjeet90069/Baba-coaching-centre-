📊 Google Sheets & Drive Setup

Step 1: Apne Google Drive mein ek nayi Google Sheet banayein.
Step 2: Sheet ke upar menu mein Extensions → Apps Script kholein.
Step 3: Neeche diye gaye button se code copy karke wahan paste karein aur Save karein.
Step 4: Upar Deploy → New deployment → Web app chunein:
• Execute as: Me
• Who has access: Anyone
Step 5: Deploy karke jo Web App URL mile usse app mein paste karke Connect dabayein!
